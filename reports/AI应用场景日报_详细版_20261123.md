# AI 应用场景与技巧日报 — 2026年11月23日

## 一、本周 AI 垂直行业落地案例

### 1. 财务 / 共享服务：摩根士丹利用 OpenAI 微调模型做"知识库问答"

**背景**：摩根士丹利（Morgan Stanley，金融服务业）财富管理部门与 OpenAI 合作，将数十万页投资策略、研究报告和流程文档转化为内部知识助手，供上万名财务顾问调用。

**具体做法**：先用 GPT-4 对文档做检索增强（RAG），再对高频问答场景做微调；顾问在内部聊天界面用自然语言提问，系统给出带出处的答案，并附原始文档链接。

**提效数据**：官方披露顾问文档检索时间从平均数十分钟降至秒级，文档利用率从约 20% 提升到 80% 以上。

**国内可复制性**：高。国内券商、银行、保险的投顾/客服知识库场景可直接借鉴"文档向量化 + 微调 + 出处引用"三件套，合规上需注意数据不出内网（可参考国产模型私有化部署）。

来源：https://openai.com/index/morgan-stanley/

### 2. 医疗：北京市卫健委推动"AI 辅助诊断"进基层医院

**背景**：北京市卫生健康委员会推动 AI 辅助诊断系统在基层医疗机构落地，覆盖影像、心电、慢病管理等场景，缓解基层医生不足问题。

**具体做法**：基层医院部署 AI 辅助诊断软件，医生阅片/看心电图时由 AI 先给出候选结论与置信度，医生复核确认；异常病例向上级医院转诊，形成"基层初筛 + 上级复核"闭环。

**提效数据**：据官方通报，试点机构影像阅片效率明显提升，部分病种（如肺结节、心电图异常）初筛准确率达到临床可用水平，基层误诊漏诊率下降。

**国内可复制性**：高，但门槛在资质。需走 NMPA 二类/三类医疗器械审批，建议从"辅助"定位切入（AI 给建议、医生做决定），并做好数据脱敏与留痕。

来源：https://wjw.beijing.gov.cn/

### 3. 电商：阿里巴巴"生意参谋"AI 助手 + 通义千问赋能商家运营

**背景**：阿里巴巴（电商平台）在商家侧推出 AI 经营助手，基于通义千问大模型，帮助中小商家做选品分析、标题优化、客服话术生成和经营诊断。

**具体做法**：商家在后台用自然语言提问（如"我这款女装下周该备多少货"），AI 结合店铺历史数据给出建议；客服场景用 AI 自动生成回复草稿并支持一键发送。

**提效数据**：阿里官方称 AI 工具可显著降低商家数据分析门槛，客服响应与内容生成环节效率提升明显（具体倍数以官方商家大会披露为准）。

**国内可复制性**：极高。国内电商 SaaS、ERP 服务商可直接复用"经营数据 + 大模型问答 + 一键执行"的产品形态，重点在数据权限隔离与商家数据安全。

来源：https://www.alibabagroup.com/

### 4. 制造：西门子 Industrial Copilot 在工厂落地

**背景**：西门子（Siemens，工业制造）与微软合作推出 Industrial Copilot，面向自动化工程师，用生成式 AI 辅助 PLC 代码生成、故障排查和产线文档理解。

**具体做法**：工程师用自然语言描述控制逻辑需求，Copilot 在 TIA Portal 中生成结构化控制语言（SCL）代码草稿，工程师审核修改；设备报警时 Copilot 结合手册给出排查步骤。

**提效数据**：西门子公开案例显示，部分自动化工程任务（如代码编写、HMI 画面生成）耗时大幅缩短，官方称可将相关工作量减少约 30%–60%（视任务复杂度）。

**国内可复制性**：中高。国内工业软件厂商（如汇川、中控）可走"工业知识库 + 代码生成 + 设备手册问答"路线，难点在工业数据封闭、OT 与 IT 安全隔离。

来源：https://www.siemens.com/global/en/company/insights/artificial-intelligence.html

## 三、可复用的操作技巧

### 技巧 1：用"角色 + 约束 + 输出格式"三件套写企业级 Prompt

**步骤**：
1. 设定角色：`你是一名有 10 年经验的财务分析师`
2. 给约束：`只基于我提供的表格数据回答，不得编造数字；不确定时回答"数据不足"`
3. 定格式：`输出为 Markdown 表格，列包括：指标、本期值、环比、风险提示`

**示例 Prompt**：
```
你是一名有10年经验的财务分析师。请基于以下季度经营数据（见附件），
找出3个最值得关注的异常指标，并给出可能原因与建议动作。
要求：只使用附件数据，不得编造；每个结论标注对应数据来源行；
输出为 Markdown 表格：指标 | 异常表现 | 可能原因 | 建议动作。
```

**适用**：财务分析、运营复盘、周报生成。核心是"不许编造 + 标出处"，可大幅降低幻觉风险。

### 技巧 2：RAG 知识库问答的"三段式"提问法

**步骤**：
1. 先问"范围"：`根据知识库，关于XX政策有哪些条款？请列出条款编号`
2. 再问"解释"：`请用通俗语言解释第3条适用于哪些情况`
3. 最后问"行动"：`如果我是小微企业主，按第3条我下一步该准备哪些材料？`

**要点**：每轮都要求"引用原文条款编号"，便于人工复核；知识库文档需先做清洗和分块（建议 300–500 字/块，带标题层级）。

**适用**：法律、HR、客服、内部制度问答。

### 技巧 3：用"少样本示例"让模型学会你的写作风格

**步骤**：
1. 准备 3–5 篇你满意的历史文案作为示例
2. Prompt 结构：`以下是过往优秀文案示例（示例1…示例5）。请模仿其语气、结构和用词，为新产品写一段 200 字推广文案。`
3. 迭代：让模型先输出 3 个版本，再按"更口语/更专业/更短"分别改写

**适用**：市场文案、公众号、邮件、客服话术。比单纯描述"写得专业一点"效果好得多。

## 四、本周最值得试的 AI 应用方向

1. **企业知识库问答（RAG）**：门槛最低、ROI 最直观。建议本周选一个部门（如 HR 或客服），把 50–100 份高频文档灌入，做 1 周试点，重点看"答案是否带出处、人工复核率"。
2. **客服/销售话术生成 + 质检**：用大模型生成回复草稿 + 对历史会话做自动质检打分，国内电商、SaaS 公司可快速验证。
3. **工业/设备手册问答**：制造业可先做"设备故障手册问答"小场景，避开核心控制系统的安全风险。
4. **财务/经营分析助手**：用结构化数据 + 大模型做"异常指标识别 + 原因假设"，注意所有结论必须人工复核。
