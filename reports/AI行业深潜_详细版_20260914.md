# AI 行业深潜 — 汽修

> 每周深挖一个垂直行业

## 一、行业现状

中国汽车保有量已超 3.5 亿辆，其中燃油车平均车龄超过 6 年，正进入维保高峰期。全国汽修门店（含 4S 店售后）约 80 万家，市场规模约 1.5 万亿元。但行业极度分散，连锁化率不足 10%，单店普遍面临三大痛点：**获客难**（依赖美团/抖音低价引流，客户忠诚度低）、**技师断层**（新能源车维修人才缺口超百万，传统机修工转型慢）、**信息不透明**（车主不懂车，报价靠"话术"，信任成本高）。利润点集中在钣喷、保养套餐、事故车维修和配件差价，毛利率 30%-50%，但净利率常被房租和人工吃掉一半。

## 二、AI 切入点

**1. 故障预诊断与报价透明化**
场景：车主描述异响/故障码，AI 结合车型、里程、历史维修记录，给出可能的故障原因和参考报价区间，减少"被宰"焦虑。工具：接入 OBD 数据的诊断 API + 大模型（如 GPT-4o、通义千问）+ 自建配件价格库。预计投入：5,000-20,000 元（API 调用 + 小程序开发）。

**2. 抖音/美团智能获客内容工厂**
场景：门店老板不会拍视频，AI 自动生成"XX 车型常见故障""保养避坑指南"等短视频脚本和文案，批量发布。工具：剪映 AI + ChatGPT/豆包 + 数字人播报。预计投入：1,000-3,000 元/月。

**3. 新能源车维修知识助手**
场景：传统技师遇到三电系统（电池/电机/电控）故障无从下手，AI 助手实时查询维修手册、故障案例、安全规范。工具：RAG 知识库（如 Dify、FastGPT）+ 车企公开维修资料。预计投入：3,000-10,000 元。

**4. 客户回访与保养提醒自动化**
场景：AI 自动识别保养到期客户，生成个性化提醒话术，通过微信/短信触达，提升复购。工具：企业微信 API + 大模型 + CRM。预计投入：2,000-8,000 元。

**5. 配件智能比价与采购**
场景：AI 聚合多个配件供应商报价，帮门店降低采购成本。工具：爬虫 + 比价算法 + 供应商 API。预计投入：5,000-15,000 元。

## 三、赚钱案例

**案例 1：途虎养车的 AI 定价与供应链**
途虎通过数字化系统整合全国门店配件价格和工时费，实现透明报价，降低车主决策成本，已成为汽修连锁龙头。来源：[途虎养车官网](https://www.tuhu.cn)

**案例 2：抖音汽修 IP 账号变现**
大量汽修技师通过抖音分享维修案例、避坑知识，积累粉丝后导流到店或卖课程/配件。典型如"汽修小张"类账号，单条爆款视频可带来数十到店客户。来源：[抖音](https://www.douyin.com)（搜索"汽修"相关账号）

**案例 3：AI 诊断工具创业**
国外已有 CarMD、FIXD 等 OBD+AI 诊断产品，通过硬件+订阅制盈利。国内类似方向仍在早期，存在机会窗口。来源：[FIXD 官网](https://www.fixdapp.com)

## 四、行动清单

1. **（最简单）** 用豆包/通义千问生成 10 条汽修短视频脚本，今天发一条到抖音测试。
2. 调研本地 5 家汽修店，问他们最头疼的获客/诊断/采购问题。
3. 用 Dify 搭一个"常见故障问答"小助手，喂入公开维修资料。
4. 联系 1-2 家配件供应商，谈 API 或批量报价合作。
5. **（最难）** 开发一个"故障描述→参考报价"小程序 MVP，找 3 家门店免费试用。
