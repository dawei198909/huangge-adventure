# AI 行业深潜 — 汽修

> 每周深挖一个垂直行业

## 一、行业现状

中国汽车维修行业市场规模约 1.5 万亿元（含维修保养、钣喷、轮胎、配件），其中独立后市场（非 4S）门店超 60 万家，从业者约 500 万人。行业高度分散、连锁化率不足 10%，单店平均月营收 15–30 万元，毛利率看似 40%+，但净利率普遍只有 5–10%。核心痛点有三个：一是**诊断依赖老师傅**，经验无法复制，招人难、留人难；二是**报价与配件不透明**，车主信任度低，获客靠低价洗车引流再转化；三是**客户流失率高**，保养到期提醒、保险续保等复购动作几乎靠人工。利润点集中在保养耗材、钣喷、变速箱/新能源三电维修等高毛利项目，以及延保、金融、配件加价。新能源车渗透率快速上升，三电维修和高压安全培训成为新缺口。

## 二、AI 切入点

**1. 故障诊断助手（维修工单 + 知识库问答）**
场景：技师上传故障码（OBD 截图）、车型、异响描述，AI 给出可能故障树、排查步骤、参考工时与配件清单。
工具：GPT/Claude 类多模态模型 + 自建维修知识库（RAG），接入汽修数据接口（如 OBD 解码器 API）。
投入：知识库整理 2–4 人月；SaaS 订阅或按店收费 300–800 元/月，单店部署成本 < 5000 元。

**2. AI 报价与配件比价**
场景：录入车型+VIN，自动匹配配件编码、多供应商比价、生成透明报价单（含工时费说明），直接发给车主微信。
工具：LLM 做非结构化配件目录解析 + 爬虫/供应商 API + 报价模板生成。
投入：开发 1–2 人月，数据源对接是主要成本；可先做半自动（人工确认后发出）。

**3. 智能客服与保养到期召回**
场景：微信/抖音私信自动应答（价格、预约、故障初筛），并基于历史工单自动生成"保养到期/年检/保险续保"提醒话术，批量触达。
工具：企业微信 + 客服机器人（如 Coze/Dify 搭建）+ CRM 数据。
投入：低，3000–1 万元/年工具费，1 周可上线。

**4. 短视频获客内容工厂**
场景：门店每天产出"换刹车片全过程""新能源电池检测"等短视频/图文，AI 生成脚本、字幕、口播与封面，批量分发抖音/视频号/小红书。
工具：剪映 AI、HeyGen/可灵类数字人、文案模型。
投入：2000–5000 元/月，1 名员工兼职运营。

**5. 新能源三电检测报告生成**
场景：电池健康度（SOH）检测后，AI 自动生成可视化检测报告与维修/置换建议，用于二手车交易背书或延保销售。
工具：检测设备数据 + 报告生成模板 + LLM 解读。
投入：中等，需与检测设备厂商合作；单份报告边际成本极低，可作为增值服务收费 100–300 元。

## 三、赚钱案例

**案例 1：途虎养车的数字化与 AI 定价体系**
途虎以"线上下单+线下工场店"模式做到万店规模，核心是用数据中台做配件定价、库存预测与门店排班，并持续投入智能诊断与客服。对独立门店的启示：透明报价+标准化服务是可复制的赚钱模型。
来源：[途虎养车官网](https://www.tuhu.cn)

**案例 2：连锁门店用企业微信+AI 做保养召回**
行业内多家区域连锁（如百援精养、天猫养车加盟店）公开分享过：通过企微 SCRM 自动打标签、到期提醒，保养复购率提升 10–20 个百分点。具体数据因店而异，建议向服务商索取案例。
来源：[天猫养车官网](https://www.tmallcar.com)、[百援精养官网](https://www.baiyuanjingsheng.com)（域名请自行核实）

**案例 3：汽修知识付费与 AI 诊断工具出海**
国内出现面向技师的"故障案例库+AI 问答"订阅产品（如汽修宝、车质网相关工具），按年收费 数百元/人，面向 500 万从业者，属于典型的高频刚需小工具生意。
来源：[汽修宝官网](https://www.qixiubao.com)

> 说明：以上为公开可查的企业与产品方向，具体营收数字未逐一核实，引用前请以官方披露为准。

## 四、行动清单（本周可做，按难度排序）

1. **【易】盘点身边 3 家汽修店**：问清他们最痛的 3 件事（诊断、获客、复购），验证需求真伪，记录原话。
2. **【易】搭一个"故障码→排查步骤"的 Demo**：用现成 LLM + 20 条真实故障案例做 RAG，发给 1 位技师试用并收集反馈。
3. **【中】做一份透明报价单模板**：选 5 个高频项目（小保养、刹车片、轮胎、空调清洗、四轮定位），用 AI 生成含工时与配件说明的报价单，找门店试用。
4. **【中】给一家店做 7 天短视频内容包**：AI 生成 21 条脚本+字幕，观察播放与到店咨询变化。
5. **【难】对接一个 OBD/配件数据源**：联系解码器厂商或配件数据商，谈 API 试用，评估数据成本与合规性。
