## 三、可复用的操作技巧

### 技巧 1：用"专家角色 + 约束条件"写出可落地的 Python 自动化脚本

很多职场人不擅长写代码，但可以用大模型生成可直接运行的数据处理脚本。

**Prompt 模板：**

```
你是一名资深 Python 数据分析师。请帮我写一个脚本，实现以下功能：
1. 读取当前目录下的 sales_2026.csv 文件（列：日期、区域、产品、销售额）
2. 按"区域+产品"分组，计算每月销售额合计和环比增长率
3. 自动剔除销售额为0或空值的异常行
4. 将结果输出为 monthly_summary.xlsx，每个区域一个 sheet

要求：
- 使用 pandas 和 openpyxl 库
- 代码加详细中文注释
- 输出完整的可直接运行的代码，不要省略
```

**使用要点**：把"我要干什么"描述得越具体（文件路径、列名、输出格式、异常处理规则），生成结果越接近可用。如果第一版报错，把报错信息原样贴回对话，让 AI 自行修复。

### 技巧 2：用"结构化摘要"快速消化 50+ 页 PDF 研报

**Prompt 模板：**

```
请阅读我上传的这份行业研报 PDF，并输出结构化摘要：
1. 核心结论（3 条以内，每条不超过 50 字）
2. 关键数据（列出至少 5 个带具体数值的统计指标，标注所在页码）
3. 产业链图谱（上游/中游/下游各有哪些代表性企业）
4. 潜在风险与争议点
5. 一句话：这份报告最值得关注的信息是什么？

要求：回答中不要出现"根据报告内容推测"这类含糊表述，所有信息必须来自原文。
```

**使用要点**：上传文件后先让 AI"通读"再提问。如果工具支持，开启"引用原文"功能，便于追溯页码。此技巧适用于券商研报、招股书、政策文件等。

### 技巧 3：用"思维链 + 反向追问"做高质量的竞品分析

**Prompt 模板：**

```
请以咨询顾问的视角，帮我分析竞品 A 和竞品 B 的差异。请先不要急着下结论，按以下步骤思考：

第1步：列出两者的目标用户画像、核心功能矩阵、定价策略
第2步：指出 A 有而 B 没有的 3 个功能，以及 B 有而 A 没有的 3 个功能
第3步：针对每个差异点，分析其背后的产品逻辑（是技术壁垒？用户需求洞察？还是商业策略？）
第4步：基于以上分析，给出对我方产品（做 C 方向的）的 3 条具体建议

最后，请反问自己：以上分析中，哪些是你基于公开资料的推测？哪些需要进一步验证？
```

**使用要点**：让 AI 先"分步思考"再给结论，避免笼统输出；末尾的反问环节能帮你识别 AI 的推测成分，避免把猜测当事实。


## 四、本周最值得试的 AI 应用方向

**企业级 AI Agent（智能体）从"演示"走向"上岗"**

过去一年，多数企业的 AI 应用停留在"对话问答"和"内容生成"层面。而 2026 年下半年，以 GPT-5.2 和 Claude 4 Opus 为代表的大模型 Agent 能力显著增强，AI 已能自主完成跨系统的多步骤任务（如自动查库存→生成采购单→发审批→更新 ERP）。

**值得试的理由**：
- 技术门槛已大幅降低，无需自研 Agent 框架，直接使用各家大模型平台提供的 Agent 编排工具（如 OpenAI Agent Kit、百度千帆 AppBuilder）即可搭建
- ROI 极高：一个成熟的 Agent 可以替代 3-5 名重复性岗位人员的工作量，且 7×24 小时在线
- 最适合的切入点：财务对账、客户工单分派、供应链库存预警、HR 简历初筛等规则相对清晰、跨系统协同多的流程

**建议**：从单个高频痛点场景切入（如"自动生成每日销售报表并推送到钉钉群"），跑通后再扩展，不要一开始就做"万能助手"。
