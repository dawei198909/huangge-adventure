# AI 行业深潜 — 汽修

> 每周深挖一个垂直行业

## 一、行业现状（市场规模/痛点/利润点）

中国汽车维修市场（含独立后市场与4S体系）规模约1.2–1.5万亿元，独立维修厂（IAM）数量超过40万家，是行业主体。痛点集中在三处：一是**诊断依赖老师傅**，资深技师稀缺、培养周期长，电控与新能源三电故障诊断门槛更高；二是**配件与报价不透明**，车主信任度低，比价流失严重；三是**获客与留存粗放**，多数门店靠位置和熟人，缺乏线上内容与私域运营能力。利润点主要在配件加价、工时费与保养套餐，钣喷和新能源三电维修是高毛利新增长点。行业整体数字化程度低，是AI落地"低竞争、高痛点"的典型洼地。

## 二、AI 切入点

**1. 故障诊断助手（语音/文字问诊 → 维修方案）**
场景：车主描述异响、故障码，技师录入OBD读数，AI给出可能故障树、排查顺序与参考工时。工具：大模型API（如通义千问、DeepSeek）+ 自有故障案例库RAG。投入：案例库整理1–2人月，API与向量库月成本数百至数千元，MVP约2–5万元。

**2. AI报价与配件比价单**
场景：拍照识别车型与损坏部位，自动生成维修项目清单、工时与配件区间报价，输出给车主增强透明度。工具：多模态视觉模型（识别车型/损伤）+ 配件价格数据库 + 报价模板生成。投入：接入配件数据源是关键成本，初期3–8万元，后续按数据源订阅计费。

**3. 门店短视频与私域内容代产**
场景：为维修厂批量生成抖音/视频号脚本、保养知识科普、案例复盘文案与配图，解决"没内容、不会拍"的问题。工具：大模型文案 + AI配音/剪辑工具（剪映AI、HeyGen类）。投入：单店月服务成本几百元，代运营模式毛利高，适合小团队切入。

**4. 保养提醒与客户召回自动化**
场景：基于维修记录与里程预测，自动生成个性化保养提醒、保险到期提醒、流失客户召回话术，走企微/短信触达。工具：大模型 + CRM/企微SCRM API + 自动化工作流（n8n/Coze）。投入：1–3万元搭建，按门店订阅收费。

**5. 新能源三电检测辅助报告**
场景：电池健康度（SOH）检测数据 → 自动生成检测报告与维修/更换建议，服务二手车交易与延保场景。工具：数据分析脚本 + 大模型报告生成 + 标准化模板。投入：需与检测设备厂商合作取数，5–10万元起，门槛较高但壁垒也高。

## 三、赚钱案例

**1. 车百灵/汽修AI问诊类SaaS**
国内已出现面向维修厂的AI诊断与知识库产品，主打"故障码+症状→维修方案"，按门店年费收费（数千元/店/年）。可参考其产品形态与定价逻辑。来源：[车百灵官网](https://www.chebailing.com)（产品与定价以官网为准）。

**2. Tekmetric / Shopmonkey（美国汽修门店管理SaaS + AI功能）**
美国头部独立维修厂管理系统，已上线AI维修建议、AI客服与报价辅助功能，验证了"门店SaaS+AI增值"的付费模式。来源：[Tekmetric](https://www.tekmetric.com)、[Shopmonkey](https://www.shopmonkey.io)。

**3. 国内汽修门店短视频代运营服务商**
抖音本地生活汽修类目兴起后，出现专门为维修厂做团购套餐设计、短视频脚本与投流的服务商，单店月度服务费常见数千元，按到店核销分成。此类服务商多为区域型团队，可在抖音本地生活服务商名录中检索核实，具体案例数据以服务商公开披露为准。

> 说明：以上为公开可查的产品/模式参考，具体营收数据未逐一核实，读者应自行尽调。

## 四、行动清单（本周可做的 5 件事）

1. **（易）访谈3家本地独立维修厂**：问清诊断靠谁、报价怎么做、客户从哪来，验证痛点优先级。
2. **（易）跑通一个故障诊断Demo**：用大模型+20条真实故障案例做RAG问答，找技师盲测准确率。
3. **（中）整理配件与工时价格样本**：收集1–2个车型体系的报价数据，评估数据获取难度与成本。
4. **（中）做一个门店内容代产样品**：选一家店，产出5条短视频脚本+1条成片，谈月度服务报价。
5. **（难）设计订阅制商业模型**：明确按店年费/按调用量/按效果分成的定价，测算单店获客成本与回本周期。
